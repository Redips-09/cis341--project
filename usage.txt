
==================================================
|                                                |
|Linux system health monitor and security daemon |
|                                                |
==================================================
|
|    USAGE: ./sysaudit.sh [OPTIONS]
|    ./sysaudit_archive.sh [-f | --force ]
|
================================================
|
|   OPTIONS:
|
|	-h		prints help 
|	--help		same as -h
|	--run		runs audit cycle once
|	--daemon	runs in daemon mode
|	--delegate	Authorize a local Linux
|			user to execute sysaudit
|
|   OVERRIDES (after --run or --daemon; they
|   replace the sysaudit.cfg value for this run):
|
|	--interval N		seconds between scans
|	--max-disk N		disk limit in MB
|	--audit-dir DIR		audit folder
|	--log-file FILE		log file
|	--log-level LEVEL	ERROR, WARN, INFO or DEBUG
|
=====================================================
|
|    EXAMPLES: 
|
|    ./sysaudit.sh --help                       
|    ./sysaudit.sh --run
|    ./sysaudit.sh --daemon
|    ./sysaudit.sh --daemon --interval 30
|    ./sysaudit.sh --run --max-disk 1
|    ./sysaudit.sh --delegate
|	                                           
======================================================
|	CONFIGURATION:
|	file: sysaudit.cfg
|	
|
|
|
|
|
|=====================================================
|	ARCHIVE JOB (sysaudit_archive.sh)
|
|	Started every night at midnight by
|	sysaudit-maintenanace.timer.
|	It packs all the *.audit files into one .tar.gz,
|	deletes the originals, then deletes archieves
|	older than RETENTION_DAYS.
|
|	Usage: ./sysaudit_archive.sh [OPTIONS]
|	
|	OPTIONS:
|	-f/ --force    runs nows, ignore the 3 day rule
|			(test purpose only)
=======================================================
|	EXIT CODES:
|
|	0	SUCCESS	
|	1	GENERIC_ERROR
|	2	IDENTITY_VIOLATION
|	3	MISSING_CONFIG
|	4	INVALID_WORKSPACE
|	5	DISK_CEILING_REACHED
|	6	LOG FILE NOT WRITTABLE
|	7	BAD CONFIGURATION VALUES
|	8	ARCHIVE_FAILED
|	9	PRUNE_FAILED
===============================================
